## About me

- 💼 Full-stack engineer focused on **backend and platform work**: TypeScript/Node and C#/.NET services in a large monorepo, event-driven systems, and the infrastructure that runs them.
- 🏗️ I like **domain-driven design and hexagonal architecture**, observability, and boring, reliable tooling.
- 🎮 On the side I'm rebuilding a classic **Macromedia Shockwave multiplayer game** from scratch: a Go server that speaks the original SMUS protocol, a native C#/MonoGame client, and a Next.js admin panel.
